# 🌸 Maira's Portfolio Website

A clean, modern, and responsive personal portfolio website built with **HTML**, **CSS**, and **JavaScript**.

---

## ✨ Features

- 💅 **Glassmorphism UI** — frosted glass cards with backdrop blur effects
- 🎨 **Gradient Background** — soft pink gradient theme throughout
- 🌀 **Animated Hero Section** — floating bubble animations in the background
- 📱 **Fully Responsive** — adapts seamlessly to mobile and desktop screens
- 🔗 **Project Showcase** — live links to all featured projects
- 🔝 **Sticky Navbar** — stays visible while scrolling

---

## 🗂️ Sections

| Section | Description |
|---------|-------------|
| **Hero** | Introduction with animated background |
| **About** | Profile picture and short bio |
| **Projects** | Cards linking to live projects |
| **Contact** | Email contact information |
